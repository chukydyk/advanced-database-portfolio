S1  Cost of safety: 300 inserts with three different write concerns
======================================================================
w:1 (primary only)           total   894 ms | average 2.98 ms per write
w:majority                   total 10876 ms | average 36.25 ms per write
w:majority + journal         total 11874 ms | average 39.58 ms per write
w:1 returns when only the primary has the write: fastest, but the write can be lost if the primary fails
before a secondary copies it. w:majority waits for a majority, so the write survives any single failure.
